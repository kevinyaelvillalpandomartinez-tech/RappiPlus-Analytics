# RappiPlus Analytics

## Project Overview

RappiPlus Analytics is an end-to-end data analytics project focused on understanding customer behavior across the digital purchase journey.

The project will analyze user activity from initial interaction through purchase, with particular attention to conversion funnels, customer retention, acquisition channels, and experimentation.

The objective is to transform behavioral and transactional data into actionable insights that can support product and business decisions.

## Business Questions

The project will explore questions such as:

- Where do users drop off in the conversion funnel?
- Which customer segments and acquisition channels achieve the highest conversion rates?
- How does customer retention evolve over time?
- Which cohorts demonstrate stronger retention behavior?
- Does a new checkout experience significantly improve conversion?
- Which factors should the business prioritize to improve customer journey performance?
